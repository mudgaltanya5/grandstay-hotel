# 🏨 GrandStay Hotel

GrandStay Hotel is a modern hotel booking website built using React.js and Bootstrap.  
The website allows users to explore hotel rooms, check room details, make bookings, complete payment, and view booking confirmation.

## 🌐 Live Demo

grandstay-hotel-xi.vercel.app
## 📌 Features

- 🏠 Home page
- ℹ️ About Hotel page
- 🛏️ Rooms listing
- 🏨 Room Details page
- 📅 Hotel booking form
- 💳 Payment page
- ✅ Booking success page
- 🖼️ Gallery page
- 📞 Contact Us page
- 🔐 Login and Signup
- 👤 User Profile
- 🚪 Logout functionality
- 💾 LocalStorage for login information
- 📧 Email confirmation using EmailJS
- 📱 Responsive design using Bootstrap

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router DOM
- EmailJS
- LocalStorage
